## 实现范围

- 新增 `UserTimeIntent`，独立保存 POINT_TIME（EXACT / NOT_BEFORE / NOT_AFTER）、MIN_DWELL 与
  lock 元数据。数据库 CHECK、复合 FK 与部分唯一索引保证字段组合、Trip/Node 归属和当前槽位唯一。
- 新增类型化 Trip command：设置/移除 point intent、设置/移除最低停留、只修改 lock。继续使用
  owner lock、Trip row lock、baseTripVersion 与一次成功 command 只递增一次 version 的边界。
- 新增只读 `POST /trips/:id/schedule/evaluate`。它基于明确 basisVersion 调用纯 domain evaluator，
  返回每个 Node 的三层时间、effective point、active intents、dwell、anchor、状态与结构化解释。
- 当前有效点按 ACTUAL > ESTIMATED > PLANNED 选择；已采用 fixedService Transport 的 PLANNED
  时刻作为固定交通锚点参与相邻 Node 判断，但不复制为 Node TemporalValue。
- EXACT、NOT_BEFORE、NOT_AFTER 与 MIN_DWELL 均按 instant 比较。缺少证据为 UNKNOWN；用户自身
  bounds 或 EXACT 与 bounds 不相容时直接为 CONFLICT，即使尚无当前计划时间。

## Migration

- P3B1 migration 只新增 enum 与 `UserTimeIntent` 表、约束、索引和 FK；不改写 P3A 的
  DayOccurrence、Node、Transport、TemporalValue 或 history 数据。
- clean DB 由标准 `prisma migrate deploy` 验证；另有 populated P3A migration integration test
  验证核心记录数量保持并验证 shape、slot uniqueness 与强归属约束。
