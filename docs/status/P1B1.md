## 实现边界

- 正式 migration 新增 `Job`、`MagicLinkDeliveryRequest` 与关联约束。
- Claim 使用 PostgreSQL `FOR UPDATE SKIP LOCKED` + 原子 UPDATE/RETURNING；有限租约支持崩溃恢复。
- 失败使用配置化、确定性、有界指数退避；达到 maxAttempts 后 FAILED。
- QUEUED 直接取消；RUNNING 使用 cooperative cancellation，不回滚已经发生的外部 I/O。
- WorkerRuntime 负责生命周期，JobRunner 负责 poll/claim/dispatch/timeout/retry/lease，
  `MAGIC_LINK_EMAIL` Handler 只负责邮件用例。
- Magic Link request 的节流、DeliveryRequest 和 Job 在同一事务；API 不再同步调用 MailSender。
- 原始 token 由 Git 外 HMAC key + DeliveryRequest ID 确定性派生，Job/数据库/日志均不保存原值；
  数据库只保存 digest。
- email delivery 为 at-least-once；真实邮件 provider 仍未配置。
