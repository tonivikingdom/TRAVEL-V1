# 验收场景与测试清单

本清单共 **84 个场景**。它们是待转化为自动化测试的规格，**不是已执行或已通过的测试**。所有时刻/票价示例均为明确的合成测试数据。

按stage过滤实施；gate不是ready的场景待对应产品边界确认。P0不要求实现全部用例，不得为刷绿而写空测试。

## 通用不变量

- Query/Preview不变更正式Trip；Adopt要么全部提交要么全部不提交。
- 相同基线、输入、Provider快照与policyVersion的纯计算结果一致。
- 单个用户不可能通过并发创建持久化两份相同自然日归属。
- 真实时间与交通不能为了让公式满足而被虚构。
- 未知不降成正常；接受风险不修改官方规则。
- 实际费用不随人数变化；无票价不会自动补零当真实金额。
- 任意用户、管理员、worker、附件下载都遵守资源归属。
- 后台持久任务重启不丢；重复请求不重复业务副作用。

JSON版本用于Codex生成参数化测试，具体test文件应随实现提交。
