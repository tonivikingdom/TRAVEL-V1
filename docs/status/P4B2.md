## Preview v2

- 新 Preview 使用 `route-adoption-preview-v2`，持久化 route corridor、generated Node 新建/复用/移除、
  protected blockers、正式 Transport segments、internal transfer details、日期归属与交通日投影。
- 历史 v1 Preview 保留原 payload，可读但返回 `SUPERSEDED_POLICY` 且 `adoptable=false`；用户需重新
  Query/Preview。
- 中转只为真正下车/换乘/等待点生成 Node。同枢纽合并仅信任 Provider `providerHubRef` 或
  `sameHubWalkingLegIndexes` 中的用户明确确认，证据记为 `SYSTEM_STRUCTURED` / `USER_CONFIRMED`；
  不使用名称相似、距离阈值或 fuzzy matching。
- 同枢纽 internal WALKING 保留在 immutable Preview 和 OperationReceipt delta 的 provenance 边界，不生成
  独立 TransportEdge；不同地点间的 WALKING 照常建立 TransportEdge。

## 原子 Adopt

- `POST /trips/:id/previews/:previewId/adopt` 只接收 `baseTripVersion` 和 `idempotencyKey`，不接收
  candidate/leg/node/time/provider payload。
- owner advisory lock 与 Trip row lock 是并发序列化边界；等待者在 `READ COMMITTED` 下看到前一个已提交
  版本，因此同 baseVersion 的两个设备最多一个成功，另一个返回 `VERSION_CONFLICT`。
- 事务内复核 owner、Trip/version、Preview v2、Preview/Snapshot/provider expiry、candidate/preview hash、当前
  corridor、generated Node 保护与 DateOwnership。Adopt 不重新调用 Provider；不匹配时返回
  `PREVIEW_STALE` / `PREVIEW_BLOCKED` / `FACT_PROTECTED`。
- 旧路线归档、generated Node 复用/移除/新建、Place、Transport、TemporalValue、TransportDayProjection、
  DateOwnership/effective range、Trip version +1、OperationReceipt 和 `ROUTE_ADOPTED` outbox 位于同一事务。
- 幂等唯一性为 owner + Trip + `ROUTE_ADOPT` + key。同 key/同 request hash 返回首次 receipt，不重复
  写入或增加版本；同 key/不同 request hash 返回 `IDEMPOTENCY_CONFLICT`。

## 正式模型与事实边界

- `AdoptedRoute` 保留 anchors、source Preview/Snapshot、candidateHash、policyVersion 和 ACTIVE/REPLACED 生命周期；
  Query 可跨越同一 ACTIVE route 所属的纯 generated corridor 重新查询，不可跳过 USER_PLANNED Node 或
  FreeAction。
- `ROUTE_GENERATED` Node 保留 adoptedRouteId、provider/providerPlaceRef/providerHubRef、sourceOperationId、
  autoReplaceable 与 userModifiedAt。只有没有 ACTUAL、UserTimeIntent、note 或用户修改的节点可自动移除；
  复用仅依据可靠 provider place/hub identity。未来 Task/Attachment 属性是同一保护规则的扩展点。
- 候选 leg 生成 `source=ADOPTED_ROUTE` 的 TransportEdge。只将候选 departure/arrival 写为 Transport
  `PLANNED + ADOPTED_TRANSPORT_FACT`，sourceRef 回指 Snapshot/Candidate/Leg；不写 Node TemporalValue，绝不写 ACTUAL。
- 被替换的 MANUAL 或 ADOPTED_ROUTE edge 都以 `USER_REPLACED` 进入 TransportEdgeHistory，并保留其原有
  强类型 TemporalValue。

## 跨日交通与日期所有权

- 一条 TransportEdge 只是一个事实；`TransportDayProjection` 按 DayOccurrence sequence 建立
  `SAME_DAY` 或 `START/OCCUPIED/END`，不会复制 TemporalValue/provider/note。国际日期线日期回拨也不按
  localDate 重排。
- 仅严格位于起止 occurrence 之间的日期是 `OCCUPIED`，禁止 ADD_PLACE_VISIT、ADD_FREE_ACTION 或 MOVE
  普通 Node 进入；START/END 仍可编辑。projection 是正式 itinerary content，中间 transport-only 日仍保留
  DayOccurrence、DateOwnership 与 effective range。路线替换后旧 projection 随旧 edge 消失并重新 reconcile。
